# E-Commerce Sales Analysis

## Overview
Analysis of an E-Commerce company's sales data using SQL to extract insights supporting marketing, inventory, and operational strategy.

## Tool Used
- MySQL (Joins, Aggregations, CTEs, Window Functions)

## Key Insights
- Identified September 2023 as peak revenue month (Rs. 29.27L)
- Mapped the top 3 customer cities — Delhi, Chennai, Jaipur — for location-based marketing
- Identified Rs. 16.2L revenue from a single premium product averaging 2 units per order
- Analyzed month-on-month sales trends and customer acquisition patterns

## Dataset
Tables: Customers, Products, Orders, OrderDetails

## Queries Covered
1. Table Structure Analysis
2. Market Segmentation Analysis
3. Engagement Depth Analysis
4. Purchase High-Value Products
5. Category-wise Customer Reach
6. Sales Trend Analysis
7. Average Order Value Fluctuation
8. Inventory Refresh Rate
9. Low Engagement Products
10. Customer Acquisition Trends
11. Peak Sales Period Identification
